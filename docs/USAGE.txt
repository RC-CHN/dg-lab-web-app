PULSE DECK — 自托管 COYOTE 2.0 Web 面板 / 常驻示波器 / 后台播放版 v1.10.0
=================================================

运行（Node.js 24 或更新版本）
  cd dg-lab-web-app
  npm ci
  cp .env.example .env
  编辑 .env，设置至少12位的 ADMIN_PASSWORD
  npm run build
  npm start
  浏览器访问 http://127.0.0.1:8787

开发模式：npm run dev
本地演示：首页连接引导中的“先体验演示” → “接管设备”。演示不访问真实房间。
真实连接：访问 /admin → 管理员口令认证 → 登录官方账号 → 加入房间 → “接管并进入控制台”（接管成功后自动跳转）。
房主手机需运行官方 App 并连接 2.0 主机。此面板不替代房主手机的蓝牙连接。

Docker 部署到自己的服务器
  把整个 dg-lab-web-app 目录复制到服务器，不需要 APK、unpacked 或 /tmp 文件。
  cp .env.example .env
  编辑 .env，设置 ADMIN_PASSWORD 为你自己的长口令（至少12位）
  docker compose up -d --build
  默认只绑定服务器 127.0.0.1:8787，适合已有反向代理。

自带 HTTPS 入口（手机和电脑使用同一域名）
  域名 A/AAAA 指向服务器，开放 80 和 443 端口。
  修改 .env：
    PANEL_DOMAIN=panel.your-domain.com
    APP_ORIGIN=https://panel.your-domain.com
    BIND_ADDRESS=127.0.0.1
    ADMIN_PASSWORD=你自己设置的至少12位口令
  docker compose --profile https up -d --build
  访问 https://panel.your-domain.com
  Caddy 自动签发证书。请替换示例域名；仓库不包含用户的服务器配置。

使用现有 Nginx/Caddy 反向代理
  转发至 127.0.0.1:8787，并将 APP_ORIGIN 设置为实际浏览器访问的完整源。
  Nginx /api/events 关闭 proxy_buffering，proxy_read_timeout 设为 60s 或更长。
  APP_ORIGIN 只含协议、域名和可选端口，不带结尾斜杠或路径。
  修改 .env 后用 docker compose up -d 重新创建服务。

同一局域网临时直接访问
  .env 设置 BIND_ADDRESS=0.0.0.0、APP_ORIGIN=http://服务器局域网IP:8787。
  手机和电脑访问该地址。公网账号登录请使用上面的 HTTPS 配置。
  不用 Docker 时：HOST=0.0.0.0 APP_ORIGIN=http://服务器IP:8787 npm start

已实现的控制
  • 手机号（+86）/邮箱密码登录、已有令牌登录，官方远程房间加入/退出。
  • 设备发现、显式接管/释放、A/B 独立或联动强度、暂停/恢复、归零。
  • 默认跟随设备回传上限（不再默认卡在100），可另设面板上限；1–30秒临时增强。
  • 设备有效/舒适/绝对上限、预热、过热、自动增强等回传值；主页面仅突出常用和异常状态。
  • 从 4.2.5 APK 提取的 24 个官方内置波形，按 2.0 算法生成。
  • 官方自由触控：经典/渐变、轴交换、四节点轴映射编辑。
  • 官方节奏触控：2×2、3×3、4×4 可配置波形格。
  • 双指分控、单通道、同步、每次交替 A/B。
  • 官方一键开火：按住临时 +1–30，松手撤销；可同步 A/B。
  • 波形队列、每段时长/幅值、循环、随机漫游、本地保存场景。
  • 定时启停：延时开始、开始后停止、固定或随机间隔；服务器后台执行。
  • 自定义波形生成、Dungeonlab+pulse 文本导入、快捷反馈、事件记录。

触控与开火的语义
  自由触控改变的是波形分量，不改变通道基础强度。
  默认 X 幅值映射：0 → 100 → 100 → 0（位置 0/.33/.66/1）。
  默认 Y 周期映射：100 → 10 → 10 → 100 ms；可交换两轴。
  触控期间覆盖波形，松手后原播放继续。开火只临时叠加强度，不选择波形。
  触控/开火请求每 125ms 续期，失去续期后约 600–700ms 撤销覆盖/增量。
  服务器断线时短任务到期后不再续发；浏览器失焦/隐藏时主动释放触点。
  “停止并归零”取消本面板播放及触控/开火，发送双通道强度归零和暂停。
  停止会更新控制代次，迟到的触控/开火请求不能恢复输出。
  已准备的队列/片段/DJ/手动节拍由服务器运行；浏览器切页、刷新、锁屏、关闭后继续。
  无后台播放任务且最后一个浏览器断开 15 秒后，服务器尝试归零并退房。
  后台任务结束时如果没有浏览器在线，也会在 15 秒后清理房间。
  断线后不自动恢复房间和播放。网络完全中断时，无法保证归零指令送达。

当前边界
  此版本针对已核对的 COYOTE_020 远程协议；不是官方 App 的完整替代品。
  蓝牙直连、3.0/OVC 控制、固件升级、云波形商店及设备端高级设置未实现。
  新增音乐模式是本地音频分析实现，不是官方 App 音频模式的逐项复刻。
  设备舒适上限/过热保护/预热只能读取，由房主 App 管理，不伪造可写开关。
  .pulse 导入支持 speed=1/2/4 及旧版省略头部设置的代码。原版2.0生成器忽略speed，按相同规则生成，不伪造加速。
  非官方服务端接口可能随 App 更新改变；扫码图形验证码不自动绕过。
  不展示 2.0 远程协议没有可靠回传的电量值。
  自定义场景只保存在当前浏览器。更换设备或清除浏览器数据后不会同步。

外观主题
  默认“暗黑街机”：黄绿A通道、冰蓝B通道、分段强度尺、圆形开火键、珊瑚红全局停止键。
  新增“复古音响”：奶油搪瓷面板、铜色A通道、墨绿B通道、模拟指针表和实体圆形开火键。
  顶栏调色盘按钮可切换“暗黑街机”“复古音响”和“原版暖色”；管理页及协作页也有相同入口。
  主题选择保存在当前浏览器，并同步到同源标签页；不修改连接、权限、播放或强度。
  无可用浏览器存储时仍可切换外观，选择仅在当前页面保留。
  电脑宽屏双通道并排；手机窄屏纵向排列，固定底部导航和停止栏。
  强度尺按当前有效上限显示；装饰图案不代表设备正在输出。
  复古指针表显示回传强度占有效上限的百分比；旁边数字为强度值。它不表示波形幅值或实时电流。
  设备尚未同步或无有效刻度时隐藏指针，不模拟读数。
  支持键盘选择、Escape收起、系统减少动态效果偏好；字体和图形不依赖外部服务。

交互流程与导航
  连接管理一次展开当前步骤：官方账号 → 远程房间 → 设备接管。
  完成的步骤折叠成摘要，可点击标题重新展开、退出或切换。
  接管成功后自动选择该设备并进入控制台；返回管理页时顶部有“进入控制台”。
  直接控制：通道控制、触控与开火。
  制作波形：波形工作室、场景组合、触控录制、画线波形、规律随机、A/B回声。
  互动玩法：音乐联动、波形DJ、多人协作、互动场景。
  主分类记住上次选中的功能；重复点击当前功能不会停止正在运行的玩法。
  底部“停止并归零”始终可达：停止所有已接管设备的播放及临时操作，并归零/暂停A/B。
  “停止波形”保留基础强度；单通道“强度归零”只设置强度，不清除播放队列。
  手机窄屏通道卡改为单列，强度增减按钮至少44×44px；底部停止栏与导航相互避让。

管理员入口与权限
  /admin 是独立管理页；普通控制页不再包含官方账号或房间登录表单。
  ADMIN_PASSWORD 未设置或短于12位时禁用真实管理，没有默认口令。
  npm start/dev 自动读取 .env；Docker Compose 将同名变量传入容器。
  管理员登录后可完整控制；其他浏览器仅能独立体验演示，或通过受限邀请协作。
  认证默认有效7天（ADMIN_SESSION_HOURS 可配置），不因页面在线自动延期；修改口令后重启服务使现有认证失效。
  登录/退出轮换Cookie与CSRF，旧会话和旧SSE不再拥有管理权限。
  返回控制台保留官方连接；退出管理或认证过期会停止任务、退房并撤销协作邀请。
  官方账号退出与管理员退出是两个独立操作，界面有明确区分。
  同一来源10分钟最多8次失败尝试；前置代理下按连接来源限流。

登录状态与部署
  每个浏览器会话独立；手机和电脑需分别完成管理员认证并登录/加入。
  实验室的协作者通过单独邀请加入同一个主面板，不需要官方账号，不获得设备接管权。
  官方账号密码不落盘；账号令牌及房间令牌只存服务器内存。重启后需重新登录。
  HttpOnly/SameSite 会话 cookie、CSRF token 和来源检查保护控制接口。
  单进程运行；不支持无会话粘性的多副本部署。不要把一个账号当公共共享入口。
  可在反向代理增加自己的访问认证；该面板不含固定默认密码或内置账号。
  官方 HTTPS 和 WSS 需要服务器可以访问 dungeon-lab.cn 域名。
  Node 24 支持 NODE_USE_ENV_PROXY=1 配合代理环境变量；容器默认开启此支持。

实验室：八种新玩法
=================
1. 触控录制：每100ms录制一帧，支持A/B叠录、另一轨循环、可选输出监听、倒放、0.25–4倍速。
2. A/B回声：延迟0.1–5秒、重复1–8次、衰减、两轨交替、奇数次幅值反向。
3. 波形DJ：双唱盘、实时混合推子、30–200 BPM、四拍循环、下一拍对齐和每拍轮换。
4. 画线波形：幅值/周期两条曲线，鼠标/触摸绘制、数值精调、镜像、反转、平滑、复制、拼接。
5. 规律随机：可复现种子、密集程度、平滑程度和变化程度，生成独立A/B轨道。
6. 多人协作：默认A/B分路累加，主控加最多7位玩家；也可选双人节奏/幅值分工或各控一轨并定时交换。
7. 互动场景：最多16个节点，每节点1–120秒、最多4个选项；可以循环跳转或结束。
8. 音乐联动：本地音频音量包络/节拍检测、按拍换波形；也支持手动BPM和敲击定拍。

片段库
  片段只含标准V2波形帧，不保存基础强度或账号。每轨最多6000帧（10分钟）。
  保存最多30个双轨片段，可以单个/批量导出JSON并导入另一浏览器。
  录制、绘图、随机、回声的结果都可以用作DJ唱盘、回声源或互动场景的波形。
  变速/回声生成的结果最多保留10分钟，超出部分截断。拼接也受该长度限制。
  普通实验的时长可以设置1–1800秒；DJ、音乐、协作和互动场景单次最多30分钟。
  场景编排与片段保存在当前浏览器；导出功能可手动转移波形数据。

协作与停止
  先接管设备，在“互动玩法 / 多人协作”创建邀请，每位玩家一个独立链接，可填写备注并单独移除。
  对方使用独立浏览器会话打开并加入，主面板显示在线后开始实验。
  默认的多人叠加将每人的(A幅值,B幅值)分路相加，不取平均。例如(20%,10%)+(30%,40%)=(50%,50%)。
  “合成设置”可改A/B各自的幅值上限和共同周期；合成值封顶，基础强度仍由主控单独设置。
  V2输出以5%为一档，向下取整；合成表显示实际发送幅值，同时列出每人的贡献。
  “清空我的贡献”只清空本人；“停止波形”停止整个协作。移除玩家不会影响其他人。
  默认30分钟过期，可设置1–60分钟；一个链接只能由一个会话兑换。
  邀请凭据位于URL片段，兑换后从地址栏移除。服务端不暴露主端账号、CSRF或房间令牌。
  协作者不能改基础强度、开火、接管设备、管理房间或启动自己的实验任务。
  互动场景可另发“场景选择”邀请，让对方选择分支；等待选择期间输出静默。
  撤销、过期、换房、释放设备、停止并归零都会使现有邀请失效。
  片段、DJ、手动节拍及无远程选择者的互动场景由服务器调度，无需浏览器续期。
  实时音频和录制监听每100ms更新、协作主端每200ms续期，失去续期1200ms后停止。
  多人叠加的协作者1500ms无新输入时撤掉其贡献；隐藏/失焦清空本人，断开SSE立即撤掉本人，其他玩家继续。
  全部协作者离线或主端离线会停止多人叠加；原双人分工模式仍在任一方1500ms失去续期后停止。
  网页内切换功能不停止已开始的播放；各玩法草稿在本次页面会话内保留。切页会结束正在录制的触控，但已录好的片段可后台回放。
  本地实时音频、录制监听和双人实时协作在页面隐藏/失焦或SSE断开后停止；它们不承诺手机锁屏继续。
  房主选择分支的互动场景可后台运行，到选择点静默等待；已绑定远程选择者的场景仍需双方在线。
  房间/设备断线、释放设备、退出管理员或认证到期都会终止后台任务，不自动恢复。
  运行代次、唯一runId及递增序号阻止过期请求重启或修改新一轮实验。
  原版触控与一键开火的逻辑不变；启动新玩法时清除旧波形和临时增量，但不改基础强度。

音乐说明
  音频文件只在浏览器读取分析，不上传到服务器。支持格式取决于浏览器的音频解码能力。
  音量包络只影响波形幅值，节拍检测只用于波形轮换，不自动提高通道基础强度。
  音乐生成与请求更新均为100ms，避免200ms采样漏掉交替波形中的非零帧。
  输出节拍为100ms，适合节奏互动；自动BPM检测对弱拍或复杂音频可能不稳定，可改用手动定拍。
  暂停或播放结束会停止音乐输出。本地音频需要保持前台运行；手动BPM由服务器运行，支持锁屏后继续。

常驻示波器与设备回传
====================
  控制台及连接管理页底部保留双通道波形小窗和全局停止。点小窗展开大图、播放进度与设备回传。
  街机：黄绿/冰蓝荧光轨迹；复古：奶油机壳与圆角绿色荧光屏；暖色：琥珀/薄荷轨迹。
  显示最近8秒的成功发送波形命令，每100ms采样，平滑滚动；支持系统减少动态效果设置。
  图形显示幅值包络，100%对应V2帧z=20，周期为x+y毫秒。触控覆盖按实际优先级显示，松手后回到原队列。
  “发送”仅代表传输层发出了指令；不是设备确认执行，也不是实际电流/电压。强度为独立的房主App回传值。
  停止后发送轨迹归零；设备暂停时保留发送轨迹并标明“设备已暂停”。浏览器断线时冻结最后状态，不伪造实时数据。
  回传明细：A/B强度、暂停、设备有效上限、舒适/绝对上限、预热比例、过热限制与热量积累、自动增强设置/累计量。
  另有设备在线、标记灯、最后变更时间和最近快捷反馈；反馈展示官方短语，不直接执行对方短语对应的控制动作。
  热量积累是房主App的0–100%计算指标，不是温度。自动增强范围：1=舒适上限、2=绝对上限、3=两种上限。
  远程适配器未同步的power/version/label默认0不作为真实电量/固件信息展示。无电流、电压或波形实测回传。
  缺失字段显示“—”；状态只在变更时推送，最后变更时间较旧不单独判定离线。

后台播放方式
============
  波形队列和片段默认勾选循环。队列持续循环至手动停止/认证到期；片段按照页面设置的最长时长运行，默认30分钟。
  DJ、手动BPM、互动场景单次最长30分钟。循环任务不需要手机持续亮屏，也不依赖浏览器计时器。
  同一浏览器重新打开时沿用会话Cookie，恢复当前任务、波形历史和进度，不重新发送开始命令。
  手机与电脑默认是独立会话，不能自动接管另一个浏览器的后台任务。
  管理员认证默认有效7天（ADMIN_SESSION_HOURS 可配置），到期会结束后台任务。服务器重启会清除任务；房主官方App与主机仍需保持连接。
  浏览器显示断线时，后台任务可能仍在服务器运行；恢复连接后再同步。已开始的任务可在任意功能页或示波器内停止。
